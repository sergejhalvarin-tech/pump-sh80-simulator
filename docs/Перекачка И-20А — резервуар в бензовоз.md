# Перекачка масла И-20А: резервуар 80 м³ → КАМАЗ-бензовоз 8 м³

## Схема

```
Резервуар 80 м³ ── патрубок ── рукав Б-2-75 (≈ 8 м) ── фильтр YS-316 ── Ш80-2,5 (в кузове JAC T9)
   ── рукав Б-2-75 (≈ 10 м) ── вверх по борту цистерны ── люк КАМАЗа (налив сверху, 2,9 м от земли)
Привод: АИР160S6 ← ПЧ INVT GD20 ← ДГУ ТСС АД-20С на прицепе
```

## Масло И-20А (ГОСТ 20799-88)

| Параметр | Значение | Источник |
|---|---|---|
| Плотность при 20 °С | 880–890 кг/м³, в расчёте **885** | паспорта поставщиков |
| Кинематическая вязкость при 40 °С | 29–35 мм²/с (в расчёте 32) | ГОСТ 20799-88 |
| Вязкость при 20 °С | **≈ 88 мм²/с** — пересчёт по ASTM D341 (32 при 40 °С, ≈ 5,3 при 100 °С) | расчёт |
| Температура застывания | не выше −15 °С | ГОСТ |
| Температура вспышки (откр. тигель) | не ниже 180 °С | ГОСТ |

88 мм²/с близко к 75 мм²/с (10 °ВУ), при которых даны характеристики насоса — подача почти паспортная.
Зимой масло густеет в разы: подача упадёт, потери на всасывании вырастут — насос/рукава нужно греть.

## Исходные данные расчёта

| | |
|---|---|
| Резервуар | вертикальный стальной, модель 3000 м³ масштабирована до 80 м³: Ø 5,73 м, 80 м³ = 3,1 м налива |
| Начальный объём в резервуаре | 72 м³ (90 %) — принято |
| Цистерна КАМАЗа | 8 м³; налив до **95 % = 7,6 м³** (запас на тепловое расширение) |
| Сечение цистерны | эллипс 2,16 × 1,18 м (замерено по модели), длина подобрана под 8 м³ |
| Насос | Ш80-2,5, 980 об/мин |
| Рукава | Б-2-75-5 ГОСТ 5398-76, Ø 75 мм |
| Высоты над землёй | вход и выход насоса 1,17 м (в кузове), патрубок резервуара 0,15 м, люк КАМАЗа 2,9 м |

## Результат (модель симулятора)

| Величина | Значение |
|---|---|
| Подача | **≈ 38,7 м³/ч** (10,8 л/с) |
| Скорость в рукаве | 2,43 м/с, Re ≈ 2075 — ламинарный режим |
| Подпор на входе | +1,8 м масла в начале, +1,5 м в конце (уровень в резервуаре выше насоса) |
| Потери на всасывании / нагнетании | 2,8 м (рукав + фильтр) / 2,0 м |
| Давление на входе / выходе | ≈ −11…−14 кПа (небольшой вакуум: потери больше подпора) / ≈ 0,03 МПа |
| **Время налива 7,6 м³** | **≈ 11 мин 47 с** |
| Масса масла в КАМАЗе | 7,6 × 885 = **6,73 т** |
| Мощность из сети двигателя | ≈ 3,3 кВт (насос почти без нагрузки — давление мало) |
| Электроэнергия за налив | ≈ 0,65 кВт·ч |
| Дизель на ДГУ за налив | ≈ 0,2 л |
| Резервуар после налива | 64,4 м³ (81 %) |
| Из полного резервуара 72 м³ | 9 полных КАМАЗов |

Методика: расход насоса берётся по его характеристике при перепаде давлений, который создают рукава; потери —
формула Дарси (λ = 64/Re в ламинарном режиме) плюс местные (вход, задвижка, колена, выход в люк) и фильтр (оценка по
Kv аналога). Уровни пересчитываются каждую секунду налива: резервуар — по площади днища, цистерна — по площади
сегмента эллипса.

## В симуляторе

- Камера **ПЛОЩАДКА** (клавиша S): резервуар, пикап с насосом, ДГУ, КАМАЗ, оба рукава. Время налива ускорено ×100
  (≈ 7 с вместо 11,8 мин), **T** — начать налив заново.
- **Стекло** — резервуар и КАМАЗ прозрачные, видно масло и как растёт уровень; в рукавах бегут частицы (синие —
  всасывание, оранжевые — нагнетание), струя падает в люк.
- **Сечение** — у резервуара снята ближняя половина, у КАМАЗа — половина со стороны пикапа, масло видно целиком.
- Панели: прогресс налива, уровни в обеих ёмкостях, график «м³ от времени», свойства И-20А, гидравлика линии
  (подача, скорость, Re, подпор, давления, потери), итог (время, т, кВт·ч, литры дизеля, остаток).
- Пикап: вишнёвый металлик под лаком только на кузове; чёрный пластик (арки, бамперы, решётка), тонированные стёкла,
  фонари, шины и диски остаются как на скане модели.
- Резервуар в заводских цветах: белая эмаль стенки, синяя и красная полосы, надпись «МАСЛО И-20А · РВС-80 №1 · 80 м³ ·
  ОГНЕОПАСНО», крыша под алюминиевую краску, жёлтое ограждение, бетонный фундамент.
- Резервуар, КАМАЗ и длинные рукава показываются только в виде «Площадка», чтобы не загораживать камеры пикапа и ДГУ.
- КАМАЗ раскрашен по деталям: оранжевая кабина, серебристая цистерна, чёрные рама и бампер, резиновые покрышки
  отдельно от стальных дисков, тонированные стёкла, светящиеся фонари.
- На резервуаре — указатель уровня (стеклянная трубка со шкалой через 0,25 м и красной меткой начального уровня),
  видно, как падает масло, даже без стекла и разреза. В стекле и разрезе — красное кольцо начального уровня в
  резервуаре и красная рамка 95 % в цистерне; по поверхности масла в цистерне расходятся круги от струи.
- Подписи «Резервуар» и «КАМАЗ» показывают текущий объём со стрелкой ▼/▲, уровень и массу.
- При входе в «Площадку» включается стекло; если налив закончен, он начинается заново.

Оценки, которые стоит уточнить на месте: начальный уровень в резервуаре, реальные длины рукавов, сопротивление фильтра,
температура масла.
