# Обвязка насоса Ш80-2,5: фланцы, рукава, фильтр грубой очистки

## Что требует руководство насоса (867-010-00-1 РЭ)

| Пункт | Требование |
|---|---|
| Прил. Б | фланцы патрубков Ø190, 8 резьбовых отверстий М14-7Н на Ø158 |
| Прил. В | присоединительные размеры фланцев по ГОСТ 1536-76, Ру 0,6 МПа; ответные фланцы — по заказу (табл. 3а) |
| 2.1.3 | нагрузки от трубопроводов на патрубки не допускаются → гибкие рукава |
| 2.2.3 | фильтр на всасывающей линии: ячейка в свету **≤ 0,25 мм** для масел и дизтоплива, ≤ 1,0 мм для нефти и мазута |
| 2.2.4 | на всасывании обратный клапан, или «гусак» на всасывании и нагнетании не ниже высоты насоса |
| табл. 2 | допустимая вакуумметрическая высота всасывания **5 м** |
| табл. 3 | манометр 0…600 кПа на выходе, мановакуумметр −100…150 кПа на входе |
| табл. 4 | подсос воздуха во фланцах всасывания → пульсации и падение подачи |

## Подобранные изделия

### Ответный фланец с ниппелем — 2 шт. (вход и выход)
Покупного «ответного фланца Ш80» с документацией нет: фланец насоса нестандартный, завод поставляет ответные под заказ.
Поэтому сделан эскиз по размерам насоса — **`Фланец ответный с ниппелем — эскиз.pdf`**:
Ø190 × 18, 8 отв. Ø15 на Ø158 (болты М14×45 в резьбу насоса), ниппель труба 78×5 длиной 130 с тремя ершами Ø82,
сталь 20 (09Г2С для мороза), прокладка паронит ПМБ-1. Это эскиз для изготовления, размеры проверить по месту.

### Рукав — Б-2-75-5 ГОСТ 5398-76
Резиновый напорно-всасывающий с текстильным каркасом и проволочной спиралью:

| Параметр | Значение (ГОСТ 5398-76) |
|---|---|
| Класс | Б — для бензина, керосина, масел |
| Внутренний диаметр | 75 мм |
| Рабочее давление | 0,5 МПа (полный перепуск насоса 0,4 МПа — запас есть) |
| Вакуум | 0,08 МПа (600 мм рт. ст.) |
| Минимальный радиус изгиба | 400 мм |
| Длина манжеты | ≥ 100 мм |
| Масса | 4,0 кг/м |
| Температура (умеренный климат) | −35…+90 °С (насос — до 70 °С) |

Крепление: на ниппель на всю длину манжеты, 2 силовых хомута 80–100 мм на конец. Текст стандарта:
https://meganorm.ru/Data2/1/4294823/4294823524.htm

### Фильтр грубой очистки — DN.ru YS-316 DN80
Паспорт: **`Фильтр DN.ru YS-316 — паспорт.pdf`**

| Параметр | Значение (паспорт) |
|---|---|
| Тип | сетчатый Y-образный, муфтовый (резьба, для DN80 — G3") |
| Ячейка сетки | **0,25 мм** — ровно по требованию насоса для масел |
| Рабочая среда | в т.ч. синтетические и минеральные масла |
| PN | 1,6 МПа |
| Корпус, сетка | сталь AISI 316, прокладка PTFE |
| Размеры DN80 | L 200, H 300 мм |
| Монтаж | на горизонтальной линии крышкой вниз, по стрелке на корпусе |

Подключение к рукавам — штуцеры-«ёлочки» с наружной резьбой G3" под рукав 75 мм.

Не подходят: фланцевый DN.ru FMY2131-F — паспорт для воды и пара, размер ячейки не указан.

## Всасывание: сколько можно поднимать масло

Масло 10 °ВУ (ν = 0,75·10⁻⁴ м²/с — вязкость, при которой даны характеристики насоса), ≈ 37,6 м³/ч, рукав 75 мм 6 м:

| Потери | м столба масла |
|---|---|
| Рукав (трение, Re ≈ 2400) + вход и 2 изгиба | ≈ 1,3 |
| Фильтр, чистый * | ≈ 1,3 |
| Скоростной напор | ≈ 0,3 |
| **Остаётся на подъём из 5 м** | **≈ 2,1 м** |
| Фильтр наполовину забит * | подъёма почти не остаётся |

\* Сопротивление YS-316 в паспорте не указано: взят Kv 131 м³/ч сетчатого фильтра DN80 с той же сеткой 0,25 мм
(Danfoss FVF) и поправка ×1,5 на вязкость масла — это оценка.

Выводы: ставить насос (пикап) как можно ближе и ниже уровня масла в ёмкости, рукав всасывания — короче; следить за
мановакуумметром и чистить фильтр, как только вакуум растёт. Холодное густое масло (больше 10 °ВУ) — подогревать
(рекомендация табл. 4 руководства).

## В симуляторе

- У насоса во всех видах: ответные фланцы с прокладкой и болтами, ниппели с ершами и хомутами, мановакуумметр на входе
  и манометр на выходе (стрелки показывают давления из модели), короткий рукав и фильтр YS-316 на всасывании.
- В мобильных видах: рукав всасывания через правый борт к бочке с маслом, рукав нагнетания через левый борт к шаровому
  крану.
- Камера **ТРУБЫ** (клавиша P): эскиз фланца, баланс всасывания «чистый/забитый фильтр», данные рукава и фильтра,
  правила монтажа.
- В режиме «Реверс» вход и выход меняются местами — фильтр окажется на нагнетании. Для реверсивной работы нужен второй
  фильтр или переключение рукавов.
