# Мобильная установка: насос Ш80-2,5 в кузове JAC T9, ДГУ на прицепе

## Схема

```
[ JAC T9 ]──фаркоп──[ прицеп с ДГУ ТСС АД-20С ]
   кузов: агрегат Ш80-2,5 + АИР160S6 на раме, ПЧ INVT GD20-011G-4 с автоматом QF1 на стойке
   кабель КГ 4×6 от ДГУ через задний борт к QF1 → ПЧ → двигатель
```

| Параметр | Значение | Источник |

| Трансмиссия | АКПП-8, полный привод | там же |
| Габариты | 5330 × 1965 × 1880 мм, база 3110 мм, клиренс 210 мм | там же; autonews.ru |

## Массы

| Что | Масса |
|---|---|
| Агрегат Ш80-2,5 с двигателем на раме | ≈ 290 кг (руководство насоса, приложение В: 280–290 кг) |
| ПЧ, стойка, автомат, кабель | ≈ 40 кг (оценка) |
| Рукава всасывания/нагнетания Ø100 | ≈ 30 кг (оценка) |
| **В кузове** | **≈ 360 кг из ≈ 980** (37 %) |
| ДГУ ТСС АД-20С-Т400-1РКМ5 | 808 кг (паспорт) |
| Одноосный прицеп с тормозом наката под ДГУ | ≈ 300 кг (оценка) |
| Топливо 80 л | ≈ 67 кг |
| **Прицеп** | **≈ 1175 кг из 1500** (78 %) |
| Автопоезд фактически | ≈ 3655 кг |

## Что важно соблюдать

- Прицеп тяжелее 750 кг — только с тормозом наката.
- Разрешённая масса автопоезда 3100 + до 1500 = до 4600 кг > 3500 кг → водителю нужна категория **BE**.
- Нагрузку на шар (обычно 4–7 % массы прицепа, ≈ 50–80 кг) и допустимую для фаркопа — сверить с его паспортом.
- Агрегат крепить к полу кузова: болтами через раму или ремнями минимум в 4 точках; рукава и кабель укладывать
  так, чтобы не перетирались о борт.
- Насос не включать на ходу. На стоянке ДГУ ставить на ровную площадку, заземлить штырём; раму агрегата и ПЧ
  подключить к тому же контуру PE.
- Пикап нарисован по габаритам из характеристик, без логотипов; форма кузова приблизительная.

## В симуляторе

Камера **ПИКАП** (клавиша 0) — вид сбоку на автопоезд, панели: загрузка кузова, кузов сверху в масштабе, массы против
пределов, характеристики машины и прицепа, правила. Камеры **ПИТАНИЕ** и **ДГУ** показывают ту же мобильную схему.
В остальных видах пикап и прицеп скрываются, чтобы не мешать смотреть на насос и двигатель.

## 3D-модель пикапа

Используется ваша модель `jac-t9ev.zip` (OBJ, 1,5 млн треугольников, PBR-текстуры 4K). Для страницы она переведена в
`models/jac_t9_web.glb`: ≈ 180 тыс. треугольников, текстуры 2K (JPEG, канал ORM собран из metallic/roughness),
сжатие meshopt, 2,9 МБ. В страницу модель встроена, поэтому файл открывается без интернета.

Подгонка при загрузке: длина — по 5330 мм; по высоте и ширине модель замеряется лучами в середине кузова и масштабируется
так, чтобы пол кузова был на 890 мм от дороги, а ширина по бортам — 1965 мм (общая высота с дугами получилась ≈ 1975 мм).
Модель исходно смотрит назад, поэтому развёрнута на 180°. Фаркоп с шаром и ремни крепления — нарисованные.
