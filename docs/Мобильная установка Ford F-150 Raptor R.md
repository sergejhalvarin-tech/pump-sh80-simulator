# Мобильная установка на Ford F-150 Raptor R

С 6.11.2026 насосный агрегат возят на **Ford F-150 Raptor R 2024** (модель пользователя: `2024-ford-f-150-raptor-r.zip`).
Он заменил JAC T9. Старое описание осталось в «Мобильная установка JAC T9.md», модели JAC лежат в `models/`.

## Характеристики (Ford, 2024 F-150 Raptor preliminary technical specifications)

| | |
|---|---|
| Кузов | SuperCrew, рама из высокопрочной стали, кабина и кузов алюминиевые |
| Двигатель | 5,2 л V8 с приводным нагнетателем, 720 л.с., 640 lb·ft (868 Н·м) |
| Трансмиссия | 10-ступенчатый автомат, полный привод (раздатка 1 : 1 / 2,64 : 1) |
| Колёсная база | 145,4″ = **3693 мм** |
| Длина × ширина (без зеркал) × высота | 232,6″ × 87,0″ × 80,6″ = **5908 × 2210 × 2047 мм** |
| Клиренс | 13,1″ = **333 мм** |
| Колея перед / зад | 74,3″ / 73,9″ = 1887 / 1877 мм |
| Шины | 37×12.50R17LT BFGoodrich KO2, кованые диски 17×8,5 |
| Топливный бак | 36 гал = 136 л |
| Кузов (5,5 фута) | длина 67,1″ = 1704 мм, глубина 21,4″ = 544 мм |

Оценки (пресса по линейке Raptor, не лист Ford): снаряжённая масса ≈ 2720 кг (6000 фунтов), полная ≈ 3200 кг,
буксировка 8200 фунтов = **3720 кг**.

## Что изменилось в симуляторе

- Модель масштабирована по длине 5908 мм без искажений. База по модели 3691 мм (по паспорту 3693), колея 1874 мм.
- Пол кузова по модели на высоте **904 мм** над дорогой (у JAC было 890), ширина кузова между бортами 1680 мм.
  Агрегат стоит на полу кузова, дорога опущена до −1014 мм от рамы агрегата.
- Высоты цистерны КАМАЗа и его люка теперь отсчитываются от дороги, поэтому расчёт налива не сместился:
  38,7 м³/ч, 11 мин 47 с.
- Рукава поднимаются над бортами Raptor (544 мм против 470 у JAC).
- Панель «Пикап» показывает данные Raptor R. Груз 360 кг при грузоподъёмности ≈ 480 кг. Разрешённая масса автопоезда
  3200 + 3720 = 6920 кг, это больше 3500 кг, поэтому **нужна категория BE**.
- Фаркоп: прицеп с ДГУ ≈ 1175 кг при допустимых 3720 кг.
