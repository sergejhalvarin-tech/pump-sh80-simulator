# Насос Ш80-2,5 — интерактивный 3D-симулятор

**Открыть:** https://sergejhalvarin-tech.github.io/pump-sh80-simulator/

Шестерённый насос Ш80-2,5 в разрезе, с двигателем АИР160S6, частотным преобразователем INVT GD20 и дизель-генератором
ТСС АД-20С. Насосный агрегат стоит в кузове Ford F-150 Raptor R, ДГУ едет на прицепе. На площадке одним насосом по
очереди наливаются КАМАЗ 8 м³ и три Scania S730 с цистернами 20 м³ из резервуара 80 м³ с маслом И-20А.

| Страница | Что там |
|---|---|
| [Симулятор](https://sergejhalvarin-tech.github.io/pump-sh80-simulator/) | насос, двигатель, питание, ДГУ, пикап, обвязка, площадка налива; на телефоне — вертикальный режим |
| [CAD и прочность](https://sergejhalvarin-tech.github.io/pump-sh80-simulator/strength.html) | насос по габаритному чертежу, вал и корпус в цвете напряжений (CalculiX) |
| [Отчёт PDF](https://sergejhalvarin-tech.github.io/pump-sh80-simulator/report.pdf) | состав, расчёт налива при +20…−10 °С, прочность, безопасность |
| [Офлайн-версия](https://sergejhalvarin-tech.github.io/pump-sh80-simulator/offline.html) | всё в одном файле (≈ 19 МБ), открывается без интернета |

## Площадка налива

- **Условия справа вверху:** температура масла, частота ПЧ, состав машин, объём цистерн, длина рукавов, время
  перестановки рукава, объём в резервуаре. Расчёт пересчитывается сразу.
- **Что учитывается:** вязкость И-20А от температуры (ASTM D341), утечки и трение насоса от вязкости, кавитация по
  допустимым 5 м вакуума, неснижаемый остаток в резервуаре.
- **Безопасность:** заземление машин, огнетушители, поддон, кнопка «СТОП», чек-лист из 10 пунктов с живыми
  проверками.

## Управление

- Кнопки **Камера**: общий вид, торец, порты, клапан, роторы, агрегат, мотор, питание, ДГУ, пикап, трубы, площадка.
- **Разрез**: корпус, стекло, сечение. Тянуть — поворот, колесо или щипок — масштаб.
- Клавиши: 1–9, 0, P, S — виды; R — реверс; M — мотор; T — начать налив заново; H — скрыть панели.

## Сборка

Сайт собирается автоматически при каждом push в `main` (GitHub Actions, `.github/workflows/site.yml`):

```bash
npm ci
npm run build
node tools/stage-site.mjs
```

- `sims/pump-shared` — модель насоса, двигатель, электрика, ДГУ, пикап, обвязка, площадка, расчёты;
- `sims/strength` — страница CAD и прочности (модели из `C:\Users\FS\Desktop\CAD\pump_sh80`);
- `tools/teardown` — сборщик (набор [teardown](https://github.com/elvarofficial/teardown), MIT);
- `tools/report.mjs` — PDF-отчёт;
- `docs/*.md` — расчёты и подбор оборудования (паспорта и руководства производителей в репозиторий не входят).
